# Clausify | Creator Legal Tools

Clausify is a comprehensive platform providing legal tools specifically built for content creators, influencers, freelancers, and digital entrepreneurs. 

## Features
- **Contract Generator**: Create legally-structured agreements for Brand Deals, Freelance Projects, Content Licenses, Photography, Coaching, and Affiliates.
- **Rate Calculator**: Calculate fair market rates for brand deals based on follower count, engagement, and content type.
- **DMCA Takedown Generator**: Generate ready-to-send DMCA notices to stop content theft.
- **IP Protection Guide**: Step-by-step guides for copyrighting and protecting digital content.
- **Legal FAQ**: 50+ common creator legal questions answered in plain English.
- **Contract Vault**: Securely store and access your generated contracts.

## Tech Stack
- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
- **Backend**: Supabase (Database + Auth)
- **PDF Generation**: Native browser print-to-PDF approach.

## Installation & Setup
1. Clone the repository.
2. Update `shared/app.js` with your Supabase credentials (`supabaseUrl` and `supabaseKey`).
3. Import `schema.sql` into your Supabase SQL Editor.
4. Serve the files from the root directory.

## Payment
Clausify operates on a Free and Pro model.
- **Free**: 3 contracts/month, Rate Calculator, FAQ.
